# Lumen Backup: product facts and pricing rules for partners

What it does: daily cloud backup for company laptops and Microsoft 365 mailboxes. Restore of a single file in minutes; restore of a whole laptop within one working day.
What it does NOT do: it does not back up on-premise servers, and it does not include antivirus.
Data stays in the Singapore region.
Price: 4 USD per device per month. Mailboxes 2 USD per user per month. Partners may give at most 10% discount without approval from Lumen.
Minimum contract: 12 months. There is no free plan; a 30-day trial is available.
Never promise: server backup, unlimited discounts, data stored in Vietnam.
